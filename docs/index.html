Everything you need, nothing you don't

Built to be small, fast and out of your way.

🎯

Element picker

Hover and click the list on the page. Press ↑ / ↓ to jump to a parent or child. Esc cancels.

🧬

Similar-element finder

Several lists that look alike? Choose exactly which ones to include, with link counts and previews.

🔭

Hover to locate

Hovering a row scrolls the page to that section and highlights it, so you always know what you're selecting.

🚫

Smart skipping

Ignores File: pages, images, PDFs, archives and same-page anchors, so you only get real content.

🔁

Polite fetching

Tune the delay, retries and retry wait. Cancel any time and keep what's been collected.

🖱️

Floating & draggable

A tiny button that remembers where you left it, isolated in a Shadow DOM so site styles can't break it.

How it works

Four clicks from a table of contents to a finished file.

Open the panel

Click the round floating button on any page.

Pick the list

Point at the element that holds your links. Tick any similar ones.

Press Start

Each page is fetched with retries and parsed for its heading and paragraphs.

Get one Markdown file

Pages are joined into a single .md that downloads automatically.

# scraped_content.md
# Chapter 1 – The Arrival

First paragraph…

Install

Not on the Web Store yet, so load it unpacked.

Get the code

Clone the repo or download it as a ZIP and unpack it.

Open chrome://extensions

Switch on Developer mode in the top-right corner.

Load unpacked

Choose the folder that contains manifest.json.

Private by design

Runs entirely in your browser.

🔒 One permission: storage 📡 Only fetches links you select 🚫 No analytics or tracking 📦 No dependencies
